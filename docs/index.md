# paperwala-pipeline

paperwala-pipeline is the tool behind [Paperwala](https://paperwala.onrender.com), a
free library of previous-year exam papers for Indian universities and school boards.

It downloads exam-paper PDFs, removes advertisements, watermarks and contact
numbers that third-party websites stamped onto the scans, checks that the paper
itself is unchanged, and stores the cleaned copy in Paperwala's own Google Drive.

It is used only by Paperwala's maintainer. The source code is public:
[github.com/krishnakantnagina/paperwala-pipeline](https://github.com/krishnakantnagina/paperwala-pipeline).
