# Terms of use

*Last updated: 28 October 2026*

cleaning exam-paper PDFs. It is not a public service, and no one other than the
maintainer signs in to it.

The source code is published as is, without warranty of any kind. Anyone using

account, their own API keys and the files they process.

The [privacy policy](privacy.html) explains how Google Drive data is used.
